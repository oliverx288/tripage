# TriPage

### Clinical Triage Training Simulator

TriPage is a free web simulator for practising the **Manchester Triage System** through interactive clinical cases.

The project was inspired by a **2026 multicenter study across 7 hospitals in Asturias**, which found that around **1 in 10 triage classifications were incorrect**.

> Educational project. The cases and results are for training purposes only and must not be used for real clinical decision making.

## Features

* Interactive triage cases
* Manchester Triage System levels
* Immediate feedback
* Practice & Study modes
* Score and performance tracking
* Statistics dashboard
* Persistent results

## Tech Stack

**Frontend**

* HTML5
* CSS3
* JavaScript

**Data**

* Supabase
* PostgreSQL

**Tools**

* Git
* GitHub

## How it works

1. Read a simulated clinical case.
2. Analyse the patient's symptoms.
3. Select the appropriate triage level.
4. Receive immediate feedback.
5. Track your performance.

## Research

The project is based on research involving:

* **7 hospitals**
* **100 nurses**
* **80% correct classifications**
* **10.1% under-triage**
* **6.3% over-triage**

[Read the study →](https://www.sciencedirect.com/science/article/pii/S1130862126000033)
